# 光伏组串IV扫描台

扫描员提交组串开路电压、短路电流与填充因子。写入后走 PostgreSQL 通知通道叫醒独立工人,工人不轮询空转。填充因子不低于 0.72 为合格,否则衰减。页面是 Vue 3。

## 清洗超期专页

顶栏点开「清洗超期专页」,阈值区、暂停记录流水区、说明区三栏并排。

- **一刀切暂停**:清洗周期超期(周期运行时长超过清洗上限)时,超期检测自动扳闸暂停整场扫描;扫描员也可随时手动扳闸。
- **写入通道真拦截**:超期检测接到退回、再接到写入通道——闸口关闭时 `POST /api/logs` 直接 409 拒收,不是只改页面开关。
- **拦住痕迹同批落库**:每一次拦回都在拒收的同一事务里写入 `pause_events` 流水,不会漏记。
- **阈值空着不许开闸**:未设清洗上限时闸口保持关闭,交单一律拦回,恢复开闸也被拒绝。
- **观察员只读**:watcher 能看阈值与暂停记录,不能扳暂停钮、不能设阈值(接口返回 403)。
- 调阈值不重置周期起点,把上限压低会立即超期;清空再设阈值等于开启新清洗周期。超期中手动恢复视为豁免本次超期,阈值变更后恢复自动检测。暂停只拦新交单,已入队的存量仍由工人处理完。

### 接口

| 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|
| GET | `/api/cleaning/status` | 登录 | 阈值、周期、超期、闸口状态 |
| GET | `/api/cleaning/events` | 登录 | 暂停记录流水(含拦截痕迹) |
| POST | `/api/cleaning/threshold` | 扫描员 | 设/清空清洗上限(小时) |
| POST | `/api/cleaning/toggle` | 扫描员 | `{"action":"pause"}` 或 `{"action":"resume"}` |

### 验收路径

1. 不设阈值交单 → 409,流水记一条拦截。
2. 设阈值 720 → 交单 201,工人正常出结论。
3. 把清洗上限压到 0.0001 → 立即超期,自动一刀切暂停;交单 409,拦截痕迹与拒收同批落库。
4. 关掉暂停 → 再送同一单 → 201。
5. watcher 登录能看阈值与流水,扳暂停钮 403。
